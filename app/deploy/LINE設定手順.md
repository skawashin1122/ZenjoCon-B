# LINE公式アカウントの作り方と、アプリへのつなぎ方

スキマ日南の通知（求人の案内・参加確定）を LINE に届けるための手順です。
所要時間：**作成 15分＋接続 15分**。作成は**先生が**行ってください（管理者になるため）。

> LINE の画面の名前や場所は、変わることがあります。見つからないときは、各画面のヘルプで「Messaging API」「Webhook」を検索してください。

---

## 全体の流れ

| 段階 | どこで | いつ |
| :--- | :--- | :--- |
| A. LINE公式アカウントを作る | LINE Official Account Manager | **今すぐ**（EC2がなくてもできる） |
| B. Messaging API を使えるようにする | LINE Official Account Manager | Aのすぐあと |
| C. 3つの値を控える | LINE Developers コンソール | Bのすぐあと |
| D. 自動応答などを切る | LINE Official Account Manager | Bのすぐあと |
| E. アプリに値を入れる | EC2 の `.env` | EC2 が HTTPS になってから |
| F. Webhook をつなぐ | LINE Developers コンソール | Eのあと |
| G. スマホで確認する | 自分のLINE | Fのあと |

---

## A. LINE公式アカウントを作る

1. パソコンで「**LINE公式アカウント 作成**」と検索し、LINE ヤフーの公式ページ（LINE for Business）を開く
2. 「**アカウントを開設する**」（無料）を選ぶ
3. **LINEアカウントでログイン**（先生の LINE でログイン。ビジネスID をメールで作ってもよい）
4. 作成フォームに入力する

   | 項目 | 入力例 |
   | :--- | :--- |
   | アカウント名 | `スキマ日南`（友だちに表示される名前） |
   | メールアドレス | 先生の学校のメール |
   | 会社・店舗名 | 学校名（または「Marine Harvest」） |
   | 業種 | 教育 などあてはまるもの |
   | 運用目的・主な使い方 | 情報発信 など |

5. 確認して「**完了**」→「LINE Official Account Manager へ」

✅ これで「未認証アカウント」ができます（審査は不要。コンテストの試用には十分です）。

### 料金について
- 無料のプラン（コミュニケーションプラン）で使えます
- ただし**無料で送れるメッセージ数には月ごとの上限**があります（友だち1人に1通送ると1通と数える）
- 開設後、Official Account Manager の「**設定 → 利用と請求**」で、現在の上限を確認してください
- 返信（友だち追加や番号を送ってきた人への自動の返事）は数に入りません

---

## B. Messaging API を使えるようにする

1. LINE Official Account Manager で、作ったアカウントを開く
2. 右上の「**設定**」→ 左のメニュー「**Messaging API**」
3. 「**Messaging APIを利用する**」を押す
4. 「**プロバイダー**」を作る（例：`Marine Harvest`）
   - プロバイダー＝アプリを作る人・団体の名前。あとから変えられないので、チーム名か学校名にする
5. プライバシーポリシー・利用規約の URL は**空欄でOK**（あとで入れられる）
6. 「OK」で完了

✅ 画面に **Channel ID** と **Channel secret** が表示されれば成功です。

---

## C. 3つの値を控える

**LINE Developers コンソール**（`https://developers.line.biz/console/`）に、同じ LINE でログインします。
B で作ったプロバイダー → チャネル「スキマ日南」を開きます。

| 控える値 | 場所 | アプリの `.env` の項目 |
| :--- | :--- | :--- |
| ① チャネルシークレット | 「**チャネル基本設定**」タブ → チャネルシークレット | `LINE_CHANNEL_SECRET` |
| ② チャネルアクセストークン（長期） | 「**Messaging API設定**」タブ → いちばん下 → 「**発行**」 | `LINE_CHANNEL_ACCESS_TOKEN` |
| ③ 友だち追加のURL | 「**Messaging API設定**」タブ → ボットのベーシックID（`@` で始まる） | `LINE_BOT_URL` に `https://line.me/R/ti/p/@xxxxxxx` の形で |

> ⚠ ① と ② は**パスワードと同じ**です。チャット・スライド・Git・スクリーンショットに**絶対に載せない**でください。
> 漏れたときは、コンソールで「再発行」すれば古いものは使えなくなります。

③ の「`@xxxxxxx`」の `@` も URL に含めます（例：`https://line.me/R/ti/p/@123abcde`）。

---

## D. 自動応答などを切る

アプリが返事をするので、LINE 側の自動の返事と二重にならないようにします。

LINE Official Account Manager → 「**設定**」→「**応答設定**」

| 項目 | 設定 |
| :--- | :--- |
| チャット | **オフ** |
| あいさつメッセージ | **オフ**（アプリが「番号を送ってください」と返すため） |
| Webhook | **オン** |
| 応答メッセージ | **オフ** |

---

## E. アプリに値を入れる（EC2 が HTTPS になってから）

EC2 に SSH で入って：

```bash
sudo nano /opt/skima/app/.env
```

次の3行に、C で控えた値を書きます（`=` のあとに空白を入れない）。

```
LINE_CHANNEL_ACCESS_TOKEN=（②）
LINE_CHANNEL_SECRET=（①）
LINE_BOT_URL=https://line.me/R/ti/p/@xxxxxxx
```

保存（`Ctrl+O` → Enter → `Ctrl+X`）して、アプリを再起動します。

```bash
sudo systemctl restart skima
```

---

## F. Webhook をつなぐ

LINE Developers コンソール → チャネル → 「**Messaging API設定**」タブ

1. **Webhook URL** に入力して「更新」
   ```
   https://<サブドメイン>.duckdns.org/line/webhook
   ```
2. 「**検証**」を押す → 「**成功**」と出ればOK
3. 「**Webhookの利用**」を**オン**

| 検証の結果 | 原因と対処 |
| :--- | :--- |
| 成功 | そのまま次へ |
| 503 | `.env` の `LINE_CHANNEL_SECRET` が空。E をやり直して再起動 |
| 401 | チャネルシークレットが違う（コピーのミス・再発行した）。E をやり直す |
| 接続できない | URL のつづり、HTTPS になっているか（`https://<ドメイン>/api/health` が開けるか）を確認 |

---

## G. スマホで確認する

1. アプリに**生徒A**でログイン → いちばん下「**LINEで受け取る**」→「**LINEとつなぐ番号を出す**」
2. 「友だち追加する」ボタン（または `LINE_BOT_URL`）から「スキマ日南」を友だち追加
3. トークに **6けたの番号**を送る → 「スキマ日南とつながりました」と返事が来る
4. アプリの画面を開き直すと「✓ LINEとつながっています」
5. **生産者**でログインして求人を公開 → 生徒A の LINE に「近くでお手伝いの募集があります」が届く
6. 生徒A が参加を押す → 生産者を LINE につないでいれば、生産者の LINE に「参加が決まりました」が届く

✅ 5 まで届けば完成です。発表のデモ動画は、この流れを撮るのがおすすめです。

---

## 試用テストのときの注意

- 生徒に友だち追加してもらう前に、**保護者・学校に「学校の公式な試用で使うLINE」だと説明**しておく
- アプリが記録するのは、生徒の **LINE の内部ID だけ**（名前・電話番号・トーク履歴は受け取らない）
- 試用が終わったら、生徒はアプリの「LINEとのつながりを外す」を押す、または「スキマ日南」をブロックすれば通知は止まる
- 管理者（先生）以外に、Official Account Manager の権限を渡さない
